Neon Coast Cover Studio turns any photo into poster cover art in the style of GTA 6's posters: a multi-panel cover, bold genre lettering and a Vice City neon-sunset grade, exported as a PNG to share. It runs offline in a desktop browser from its own static files — your photos never leave the machine.

## Run it

```sh
node serve.ts
```
